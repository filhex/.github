# FILHEX

**ECU file service for tuners and workshops. Pay per processed File — not per licence.**

Upload the original ECU File in the FILHEX Windows app. The free scan reads the Brand and the ECU from the File and lists
the Solutions that apply: Stage 1, DPF, EGR, AdBlue / SCR, DTC clear and more. Select what you need and download the
result File.

- **1 Credit = 1 processed File**, with every Solution you select on that File included
- **The scan is free**: see what is supported before you pay
- **A failed job returns its Credit**
- **3 free Credits** for a new Workspace after email verification
- Credit packs: €5 for 1 · €40 for 10 · €150 for 50 · €200 for 100. Credits never expire, no subscription
- **Hex Editor** in the app to compare the original and the result File side by side
- Support in English, same-day replies by email

Emissions Solutions are not road-legal in most of Europe; the workshop stays responsible for legal use.
